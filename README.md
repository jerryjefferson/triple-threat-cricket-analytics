# Triple Threat Cricket Analytics

## Project Overview

An end-to-end cricket performance analytics project built using Python, SQL, and Power BI.

The project analyzes batting, bowling, and fielding statistics from the Triple Threat cricket tournament and transforms raw player-level data into meaningful performance insights and an interactive Power BI dashboard.

## Objectives

- Analyze batting, bowling, and fielding performance.
- Compare players and teams using key performance indicators.
- Identify top performers and multi-discipline contributors.
- Build a consistent player-performance scoring model.
- Demonstrate an end-to-end data analytics workflow using Python, SQL, and Power BI.

## Tools & Technologies

- Python
- Pandas
- SQL
- SQLite
- Power BI
- Excel

## Project Workflow

Raw Data → Data Cleaning → Data Validation → Analysis → SQL → Power BI → Insights

## Key Results

- Analyzed 21 players across 3 teams.
- Consolidated batting, bowling, and fielding datasets.
- Validated key cricket metrics including strike rate, economy, bowling average, and fielding dismissals.
- Performed SQL-based player and team analysis.
- Developed a weighted overall performance score using batting, bowling, and fielding contributions.
- Built an interactive Power BI dashboard for player and team performance analysis.
