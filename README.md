# Triple Threat Cricket Analytics

## 📊 Project Overview

An end-to-end cricket performance analytics project built using **Python, Pandas, SQL, SQLite, and Power BI**.

The project analyzes batting, bowling, and fielding statistics from a three-team cricket tournament and transforms raw tournament data into structured player and team performance insights.

## 🎯 Business Problem

Tournament statistics were available across separate batting, bowling, and fielding datasets, making it difficult to compare players consistently across multiple dimensions of performance.

The objective was to build an analytical solution that could:

- Consolidate player-level batting, bowling, and fielding data.
- Clean and validate raw tournament statistics.
- Compare players and teams using meaningful KPIs.
- Identify top performers and multi-discipline contributors.
- Develop a consistent overall player-performance score.
- Present the analysis through SQL and an interactive Power BI dashboard.
